这份档案怎么来的

不是手工整理的页面，而是一条可重复执行的流水线：换一台机器，只要有笔记目录，就能生成同样的数据与页面。

  1. 01

    同步

    微信读书 → Obsidian。用 obsidian-weread-plugin 把划线、想法、进度和时长同步成本地 Markdown。

  2. 02

    解析

    Node 脚本读取 frontmatter 与正文区块，按书聚合章节，去重、清洗时间，输出 JSON。

  3. 03

    生成

    由 JSON 渲染静态页面，不依赖框架和第三方请求；样式与脚本都是手写的。

  4. 04

    校验

    单元测试覆盖解析边界，隐私检查确认没有原文、Cookie、联系方式进入产物。

build
WEREAD_DIR=/path/to/WeRead npm run build
node --test
npm run check
